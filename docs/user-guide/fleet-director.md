# 🏥 คู่มือผู้อำนวยการอนุมัติคำขอรถ

คู่มือนี้สำหรับผู้อำนวยการหรือผู้รับมอบหมาย Fleet ที่อนุมัติคำขอขั้นสุดท้าย

> 💡 **ภาพรวมเร็ว:** เปิดงานรออนุมัติ → ตรวจคำขอและ Assignment → อนุมัติ ส่งกลับ หรือไม่อนุมัติ

## ✅ อนุมัติคำขอ

1. เปิด `จองรถ > งานรอตรวจสอบและอนุมัติคำขอใช้รถ`
2. ดูส่วน `ผู้อำนวยการอนุมัติ`
3. เปิดรายละเอียด ตรวจภารกิจ ช่วงเวลา ผู้เดินทาง รถ คนขับ และผลตรวจของหัวหน้าฝ่ายบริหาร
4. เลือก `อนุมัติ`, `ส่งกลับ` หรือ `ไม่อนุมัติ`

เมื่ออนุมัติ ระบบส่งงานให้คนขับรับทราบ การส่งกลับและไม่อนุมัติต้องระบุเหตุผล

> 🔎 **ควรตรวจ:** วัตถุประสงค์ ช่วงเวลา ปลายทาง รถ คนขับ และจำนวนผู้ร่วมเดินทางก่อนตัดสินใจ

## 📊 Dashboard และรายงาน

- `Dashboard รถ` แสดงงานรออนุมัติและภาพรวมตามสิทธิ์
- `ปฏิทินรถ` ใช้ดูตารางการเดินทางร่วมกัน
- `รายงาน` ใช้ดูการใช้รถและ Feedback ในภาพรวม

รายงาน Feedback ไม่แสดงตัวผู้ประเมิน และห้ามนำคะแนนไปทำ Leaderboard คนขับ

## 🤝 Delegation

การมอบหมายใช้ Scope `FLEET` และ permission ที่ตรงกับขั้นตอน ระบบบันทึกทั้งผู้ดำเนินการจริงและข้อมูลการมอบหมายใน Audit
