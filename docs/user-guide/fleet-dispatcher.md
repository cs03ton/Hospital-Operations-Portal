# 🚌 คู่มืองานยานพาหนะและการจัดรถ

คู่มือนี้สำหรับผู้ได้รับสิทธิ์งานยานพาหนะในการจัดรถและคนขับ

> 💡 **ภาพรวมเร็ว:** เปิดคิว → ตรวจความพร้อม → จัดรถและคนขับ → ส่งหัวหน้าฝ่ายบริหารตรวจสอบ

## 🔄 Workflow ของคุณ

`ผู้ขอส่งคำขอ → งานยานพาหนะจัดรถ/คนขับ → หัวหน้าฝ่ายบริหารตรวจสอบ`

## 🚘 จัดรถและคนขับ

1. เปิด `จองรถ > คิวจัดรถ`
2. ค้นหาด้วยเลขคำขอ ผู้ขอ ปลายทาง หรือสถานะ
3. เปิดรายละเอียดและตรวจช่วงเวลา จำนวนผู้เดินทาง ความต้องการพิเศษ และเอกสารประกอบ เช่น หนังสือเชิญประชุม ก่อนพิจารณา
4. ตรวจ Availability ของรถและคนขับ
5. เลือกรถและคนขับ แล้วบันทึก Assignment

หลังจัดรถ ระบบแจ้งผู้มีสิทธิ์หัวหน้าฝ่ายบริหารผ่านการแจ้งเตือนใน HOP และ LINE ส่วนบุคคลเมื่อบัญชีนั้นผูก LINE แล้ว ข้อมูลกลุ่มยานพาหนะสำหรับเหตุการณ์ Fleet ตั้งได้ที่ `จัดการระบบ` > `กลุ่มแจ้งเตือนส่วนกลาง`

ระบบตรวจรถ/คนขับไม่พร้อม งานซ้อน วันลาคนขับ ใบขับขี่หมดอายุ สถานะ active และ Compatibility ที่กำหนด

> ✅ **ควรตรวจ:** รถและคนขับต้อง active, ไม่ติดงานซ้อน, ไม่อยู่ในช่วง unavailable และใบขับขี่ยังไม่หมดอายุ

## ↩️ ส่งกลับหรือไม่รับดำเนินการ

- ข้อมูลคำขอไม่ถูกต้อง: ส่งกลับ `REQUESTER` พร้อมเหตุผล
- ข้อมูลรถหรือคนขับต้องแก้ไข: จัดการในคิว Dispatcher
- ไม่สามารถดำเนินการ: เลือกไม่อนุมัติและระบุเหตุผลที่ผู้ขอเข้าใจได้

## 🔁 เปลี่ยน Assignment

ห้ามแก้หรือลบ Assignment เดิม ระบบจะปิดรายการเดิมและสร้างรายการใหม่ที่อ้างอิงรายการก่อนหน้า ต้องระบุเหตุผลทุกครั้ง และตรวจสอบ Conflict ก่อนยืนยัน

## ⚠️ ข้อควรระวัง

- ห้ามจัดคนขับที่ลา ใบขับขี่หมดอายุ หรือ inactive
- อย่าใช้ LINE เป็นแหล่งข้อมูลหลัก ให้ตรวจรายละเอียดใน HOP เสมอ
- หากกดพร้อมกันและพบ Conflict ให้รีเฟรชก่อนดำเนินการใหม่
