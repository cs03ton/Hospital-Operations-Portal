# ⚙️ คู่มือผู้ดูแลระบบจองห้องประชุม

คู่มือนี้สำหรับ Admin และ SuperAdmin หรือผู้ได้รับสิทธิ์จัดการรายการจองและทะเบียนห้องประชุม

> 💡 **หลักการสำคัญ:** แก้ไขข้อมูลเท่าที่จำเป็น บันทึกเหตุผลเมื่อยกเลิก และตรวจปฏิทินก่อนเปลี่ยนห้องหรือเวลา ระบบเก็บประวัติและ Audit ตามบัญชีผู้ดำเนินการ

## 🔐 สิทธิ์ที่เกี่ยวข้อง

| Permission | ความสามารถ |
|---|---|
| `MeetingRoom.Calendar.View` | ดูปฏิทิน ห้อง และรายละเอียดรายการ |
| `MeetingRoom.Booking.Manage` | ดูรายการทั้งหมด แก้ไข และยกเลิกรายการ |
| `MeetingRoom.Room.Manage` | เพิ่มหรือแก้ไขทะเบียนห้องประชุม |

## 📋 จัดการรายการจอง

1. เปิด `จองห้องประชุม` > `จัดการรายการและห้อง`
2. เลือกแท็บ `รายการจองทั้งหมด`
3. ค้นหาจากหัวข้อหรือวัตถุประสงค์ และกรองสถานะตามต้องการ
4. เปิดรายละเอียดด้วยเลขรายการ `MR-xxxxxx`
5. ตรวจผู้จอง กลุ่มงาน ห้อง ช่วงเวลา จำนวนผู้เข้าร่วม วัตถุประสงค์ คำขอเพิ่มเติม Link และไฟล์แนบ
6. ตรวจประวัติรายการก่อนดำเนินการ

## ✏️ แก้ไขรายการ

ผู้ดูแลสามารถเปลี่ยนข้อมูลรายการจองได้เมื่อได้รับข้อมูลที่ถูกต้องจากผู้จอง

1. เปิดรายการที่ต้องการแก้ไข
2. ตรวจปฏิทินและความจุของห้อง
3. แก้ห้อง วัน เวลา หรือรายละเอียดที่เกี่ยวข้อง
4. บันทึกและตรวจผลลัพธ์อีกครั้ง

ระบบป้องกันการจองห้องเดียวกันทับช่วงเวลา หากเกิด conflict ให้โหลดข้อมูลล่าสุดแล้วเลือกห้องหรือเวลาใหม่ ห้ามแก้ข้อมูลรายการอื่นเพื่อหลีกเลี่ยง conflict โดยไม่มีการประสานงาน

เมื่อแก้ไขสำเร็จ ระบบส่ง Notification ให้ผู้จองและบันทึก Audit ของผู้ดำเนินการ

## 🚫 ยกเลิกรายการ

1. เปิดรายละเอียดรายการสถานะ `ยืนยันแล้ว`
2. กด `ยกเลิกรายการ`
3. ระบุเหตุผลที่ชัดเจน เช่น ผู้จองยกเลิกกิจกรรมหรือเปลี่ยนสถานที่
4. ยืนยันการยกเลิก
5. ตรวจว่าสถานะเปลี่ยนเป็น `ยกเลิกแล้ว`

การยกเลิกจะคืนช่วงเวลาให้ห้อง ระบบแจ้งผู้จองและเก็บเหตุผลไว้ในประวัติและ Audit ไม่ควรใช้เหตุผลที่มีข้อมูลผู้ป่วยหรือข้อมูลส่วนบุคคลเกินความจำเป็น

## 🏢 จัดการทะเบียนห้อง

1. เปิดแท็บ `ทะเบียนห้อง`
2. กดเพิ่มห้อง หรือเลือกแก้ไขห้องเดิม
3. กรอกรหัสห้อง ชื่อห้อง สถานที่ และความจุ
4. ตั้งสถานะ `เปิดใช้งาน` สำหรับห้องที่พร้อมให้จอง
5. กดบันทึก

รหัสห้องต้องไม่ซ้ำ หากห้องหยุดให้บริการชั่วคราวหรือเลิกใช้งาน ให้เปลี่ยนเป็น `ปิดใช้งาน` เพื่อรักษาประวัติรายการเดิม

> ⚠️ การปิดห้องไม่ควรใช้แทนการยกเลิกรายการที่มีอยู่ ตรวจรายการในอนาคตและประสานผู้จองก่อนเปลี่ยนสถานะห้อง

## 🔔 Notification และ Audit

- สร้างรายการใหม่: แจ้งผู้มีสิทธิ์จัดการรายการจอง
- ผู้ดูแลแก้ไขรายการ: แจ้งผู้จอง
- ผู้ดูแลยกเลิก: แจ้งผู้จองพร้อมเหตุผล
- การสร้าง แก้ไข ยกเลิก และบันทึกห้อง: เก็บ Audit ตามบัญชีและ Correlation ID

## ✅ Checklist ประจำวัน

- [ ] ตรวจรายการจองใหม่และคำขอเพิ่มเติม
- [ ] ตรวจ conflict หรือการเปลี่ยนห้องที่ต้องประสานงาน
- [ ] ตรวจห้องปิดใช้งานกับรายการในอนาคต
- [ ] ตรวจจำนวนผู้เข้าร่วมเทียบความจุห้อง
- [ ] ใช้เหตุผลที่ชัดเจนและไม่มีข้อมูลอ่อนไหวเมื่อยกเลิก

## 🧯 แก้ปัญหาเบื้องต้น

- บันทึกห้องไม่ได้: ตรวจรหัสซ้ำ ชื่อห้อง ความจุ และโหลดข้อมูลล่าสุด
- แก้รายการไม่ได้: ตรวจสิทธิ์ `MeetingRoom.Booking.Manage` และสถานะปัจจุบัน
- เวลาใหม่ชนรายการอื่น: ตรวจปฏิทินทุกห้องแล้วเลือกช่วงใหม่
- ผู้จองไม่ได้รับ Notification: ตรวจ Notification ของบัญชีผู้จองและ Audit ด้วยเลขรายการ
- ไฟล์แนบเปิดไม่ได้: ตรวจสิทธิ์ ชื่อไฟล์ และไฟล์ใน storage โดยไม่คัดลอกข้อมูลอ่อนไหวไปยังช่องทางภายนอก
