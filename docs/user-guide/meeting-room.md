# 🏢 คู่มือจองห้องประชุม

คู่มือนี้สำหรับผู้ใช้งานที่ต้องการตรวจสอบตารางห้องประชุม สร้างรายการจอง และติดตามรายการของตนเองใน Hospital Operations Portal (HOP)

> 💡 **ภาพรวมเร็ว:** ตรวจห้องว่างในปฏิทิน → กรอกรายละเอียดการประชุม → ตรวจรายการที่ยืนยันแล้ว → เปิดรายละเอียดหรือไฟล์แนบเมื่อจำเป็น

## 🧭 เมนูที่เกี่ยวข้อง

| เมนู | ใช้ทำอะไร |
|---|---|
| `จองห้องประชุม` > `Dashboard ห้องประชุม` | ดูสถานะห้องปัจจุบัน ตารางใช้ห้อง และรายการจองที่จะมาถึง |
| `จองห้องประชุม` > `ปฏิทินห้องประชุม` | ดูตารางทุกห้องหรือกรองเฉพาะห้อง |
| `จองห้องประชุม` > `รายการจองของฉัน` | ค้นหาและติดตามรายการที่ตนเองสร้าง |
| `จองห้องประชุม` > `จองห้องประชุม` | สร้างรายการจองใหม่ |

เมนูที่เห็นขึ้นอยู่กับสิทธิ์ของบัญชี หากไม่เห็นเมนูที่ควรใช้ ให้ติดต่อผู้ดูแลระบบเพื่อตรวจสิทธิ์ ไม่ควรใช้ URL ของผู้อื่นเพื่อข้ามขั้นตอน

## 📊 Dashboard ห้องประชุม

หน้าแรกของเมนูจองห้องแสดงรูปห้องหรือภาพประกอบ สถานะ `กำลังใช้งาน`, `ว่าง`, `ใกล้ถึงใช้งาน` (เริ่มใน 30 นาที) และ `ไม่พร้อมใช้งาน` ตามเวลาปัจจุบันของไทย เลือกวันที่เพื่อดูตารางการใช้ห้องและกราฟของวันนั้นได้ ห้องปิดใช้งานยังเห็นในภาพรวม แต่เลือกจองไม่ได้ กด `ดูรายละเอียด` เพื่อไปตรวจปฏิทินของห้องนั้น

## 📅 ตรวจสอบปฏิทินและห้องว่าง

1. เปิด `ปฏิทินห้องประชุม`
2. เลือกดูแบบ `เดือน`, `สัปดาห์` หรือ `รายการ`
3. ใช้ปุ่ม `ก่อนหน้า` และ `ถัดไป` เพื่อเปลี่ยนช่วงเวลา
4. เลือก `ทุกห้อง` หรือกรองชื่อห้องที่ต้องการ
5. กดรายการในปฏิทินเพื่อดูหัวข้อ ผู้จอง ห้อง และช่วงเวลา
6. กด `Refresh` เมื่อต้องการโหลดข้อมูลล่าสุดก่อนสร้างรายการ

> ✅ **แนะนำ:** ตรวจปฏิทินอีกครั้งก่อนกดบันทึก โดยเฉพาะการประชุมเร่งด่วนหรือช่วงเวลาที่มีผู้ใช้งานหนาแน่น

## 📝 สร้างรายการจอง

1. กด `จองห้อง` จากหน้าปฏิทิน หรือเปิดเมนู `จองห้องประชุม`
2. ตรวจชื่อผู้จองและกลุ่มงานที่ระบบแสดง
3. เลือกห้อง วันที่ เวลาเริ่ม และเวลาสิ้นสุด
4. ระบุหัวข้อประชุมและวัตถุประสงค์
5. ค้นหาและเลือกผู้เข้าประชุมที่ทราบชื่อได้ ผู้จองถูกนับรวมอัตโนมัติ รายชื่อให้เลือกไม่รวมบัญชี Admin/SuperAdmin
6. ระบุ `จำนวนผู้เข้าประชุมทั้งหมด (รวมผู้จอง)` แม้ยังไม่ทราบชื่อทุกคน จำนวนต้องไม่น้อยกว่าจำนวนคนที่ระบุชื่อ และไม่เกินความจุห้อง
7. เพิ่มคำขอ เช่น อุปกรณ์ อาหารว่าง หรือน้ำ ตามความจำเป็น
8. ใส่ Link ประชุม หากเป็นการประชุมแบบออนไลน์หรือแบบผสม
9. แนบเอกสาร PDF, Word, Excel หรือ PowerPoint ได้สูงสุด 5 ไฟล์ ไฟล์ละไม่เกิน 10 MB โดยหลีกเลี่ยงข้อมูลผู้ป่วยและข้อมูลลับที่ไม่จำเป็น
10. ตรวจข้อมูลแล้วกดบันทึก

เมื่อห้องว่าง ระบบยืนยันรายการทันทีและออกเลขรายการรูปแบบ `MR-000001`

## ⚠️ เมื่อเวลาจองชนกัน

ระบบไม่อนุญาตให้มีรายการสถานะยืนยันแล้วของห้องเดียวกันทับช่วงเวลากัน หากบันทึกไม่สำเร็จเพราะเวลาชนกัน:

1. กลับไปตรวจปฏิทินล่าสุด
2. เลือกเวลาใหม่หรือห้องอื่น
3. ตรวจเวลาเริ่มและเวลาสิ้นสุดว่าเรียงลำดับถูกต้อง
4. บันทึกรายการอีกครั้ง

## 📋 ติดตามรายการของฉัน

1. เปิด `รายการจองของฉัน`
2. ค้นหาจากหัวข้อหรือวัตถุประสงค์
3. กรองสถานะ `ยืนยันแล้ว` หรือ `ยกเลิกแล้ว`
4. กด `ดูรายละเอียด` เพื่อตรวจห้อง เวลา ผู้จอง จำนวนคน รายชื่อผู้เข้าประชุมที่ระบุไว้ วัตถุประสงค์ คำขอเพิ่มเติม Link ประชุม และประวัติรายการ
5. เปิดไฟล์แนบจากหน้ารายละเอียดเมื่อมีสิทธิ์เข้าถึง

| สถานะ | ความหมาย |
|---|---|
| `ยืนยันแล้ว` | ห้องถูกจองในช่วงเวลาที่ระบุ |
| `ยกเลิกแล้ว` | รายการไม่ใช้ห้องแล้วและยังเก็บไว้เป็นประวัติ |

ผู้ใช้งานทั่วไปไม่สามารถแก้ไขหรือยกเลิกรายการที่ยืนยันแล้วด้วยตนเอง หากข้อมูลผิดหรือไม่ใช้ห้องแล้ว ให้แจ้งผู้ดูแลรายการจองพร้อมเลข `MR-xxxxxx`

## 🔔 การแจ้งเตือน

เมื่อสร้างรายการ ระบบแจ้งผู้มีหน้าที่จัดการรายการจอง หากผู้ดูแลแก้ไขหรือยกเลิกรายการ ระบบจะแจ้งกลับผู้จองผ่าน Notification ใน HOP

## 🧯 แก้ปัญหาเบื้องต้น

- ไม่เห็นห้อง: ห้องอาจถูกปิดใช้งาน หรือบัญชีไม่มีสิทธิ์ดูปฏิทิน
- บันทึกไม่ได้: ตรวจช่องบังคับ จำนวนผู้เข้าร่วม ช่วงเวลา และรายการอื่นที่อาจจองทับกัน
- ไม่เห็นรายการของตนเอง: ล้างตัวกรอง ค้นหาด้วยเลขรายการหรือหัวข้อ แล้วกด Refresh
- เปิดไฟล์แนบไม่ได้: ตรวจว่า Login อยู่และมีสิทธิ์ดูปฏิทิน หากยังไม่ได้ให้แจ้งเลขรายการและชื่อไฟล์แก่ผู้ดูแล
