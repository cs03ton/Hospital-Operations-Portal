# 👨‍✈️ คู่มือพนักงานขับรถ

คู่มือนี้สำหรับพนักงานขับรถ ใช้งานได้ทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

> 💡 **ภาพรวมเร็ว:** ตรวจงาน → รับทราบ → ตรวจรถ → บันทึกเลขไมล์เริ่มต้น → เดินทาง → บันทึกเลขไมล์สิ้นสุด

## 📋 งานขับรถของฉัน

เปิด `จองรถ > งานขับรถของฉัน` ระบบแสดงเฉพาะ Assignment ของผู้ใช้ที่เข้าสู่ระบบ รวมทั้งงานปัจจุบันและประวัติงานเดิม คนขับไม่เห็นเมนูคำขอใช้รถของผู้ขอ

## 👀 รับทราบงาน

1. เปิดงานที่มีสถานะ `รอคนขับรับทราบ`
2. ตรวจวันเวลา ปลายทาง รถ และจำนวนผู้เดินทาง
3. เลือก `รับทราบงาน` หรือปฏิเสธพร้อมเหตุผลตามสิทธิ์

## 🚦 เริ่มเดินทาง

1. ตรวจสภาพรถและยืนยันว่าปลอดภัยพร้อมเดินทาง
2. ระบบดึงเลขไมล์ล่าสุดของรถเป็นค่าเริ่มต้น หากไม่ถูกต้องให้ตรวจสอบก่อนบันทึก
3. ระบุเลขไมล์เริ่มต้นและหมายเหตุที่จำเป็น
4. กด `เริ่มเดินทาง` และยืนยันใน Dialog ของระบบ

> ✅ **ก่อนออกเดินทาง:** ตรวจสภาพรถ ความปลอดภัย เชื้อเพลิง เอกสาร และเลขไมล์ให้เรียบร้อย

## 🏁 ปิดทริป

1. ระบุเลขไมล์สิ้นสุด ซึ่งต้องไม่น้อยกว่าเลขไมล์เริ่มต้น
2. บันทึกเหตุการณ์หรือหมายเหตุถ้ามี และแนบไฟล์ตามสิทธิ์
3. กด `จบทริป`

เมื่อสำเร็จ ระบบกลับไปหน้างานขับรถของฉันและแสดงสถานะ `เสร็จสิ้น` สีเขียว ห้ามใช้เลขไมล์ประมาณการ หากเลขไมล์ผิดให้แจ้ง Fleet Admin เพื่อทำ Mileage Override พร้อมเหตุผลและ Audit

## 🔐 ความเป็นส่วนตัว

ห้ามส่งเลขใบขับขี่ เหตุผลการลาของคนขับ หรือข้อมูลผู้ป่วยผ่าน LINE Group
