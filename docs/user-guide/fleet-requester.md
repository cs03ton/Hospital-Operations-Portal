# 🚐 คู่มือขอใช้รถและผู้ร่วมเดินทาง

คู่มือนี้สำหรับเจ้าหน้าที่ หัวหน้าหน่วยงาน ผู้อำนวยการ และผู้ดูแลที่ต้องการขอใช้รถราชการ

> 💡 **ภาพรวมเร็ว:** สร้างคำขอ → เพิ่มผู้ร่วมเดินทาง → ส่งคำขอ → ติดตามสถานะ → เดินทาง → ให้ Feedback

## 🧭 งานที่คุณทำได้

- สร้างและบันทึกร่างคำขอใช้รถ
- เพิ่มผู้ร่วมเดินทางที่มีบัญชี HOP
- ส่งคำขอ ติดตามสถานะ และดูปฏิทินรถ
- แก้ไขรายการที่ถูกส่งกลับ และยกเลิกตามเงื่อนไขของ Workflow
- ให้ Feedback เมื่อเป็นผู้เดินทางจริงและทริปเสร็จสิ้น

## 📝 สร้างคำขอ

1. เปิด `จองรถ > คำขอใช้รถ`
2. กด `สร้างคำขอ`
3. ระบุภารกิจ ประเภทการเดินทาง ปลายทาง วันเวลาออกเดินทางและคาดว่าจะกลับ
4. ตรวจเบอร์โทรผู้ประสานงาน ระบบดึงจากข้อมูลพนักงานและล็อกช่องไว้ หากยังไม่มีเบอร์ในข้อมูลพนักงาน ให้กรอกเบอร์ติดต่อสำหรับคำขอนี้
5. ตัวเลือก `ผู้ขอร่วมเดินทางด้วย` เปิดไว้เป็นค่าเริ่มต้น หากไปคนเดียว ระบบนับเป็น 1 คนได้ทันที หากปิดตัวเลือกนี้ ต้องระบุผู้ร่วมเดินทางอย่างน้อยหนึ่งคน จำนวนผู้เดินทางไม่รวมคนขับ
6. เลือกผู้ร่วมเดินทางคนอื่นเพิ่มเติมได้ รายชื่อให้เลือกไม่รวมบัญชี Admin/SuperAdmin
7. แนบเอกสารประกอบได้ถ้ามี เช่น หนังสือเชิญประชุม รองรับ PDF, JPG, PNG, DOC และ DOCX สูงสุด 2 ไฟล์ ไฟล์ละไม่เกิน 5 MB
8. ตรวจสอบข้อมูล แล้วเลือก `บันทึกร่าง` หรือ `ส่งคำขอ`

วันเวลาแสดงเป็นวัน/เดือน/พ.ศ. และเวลา 24 ชั่วโมง เวลากลับต้องอยู่หลังเวลาออกเดินทาง ผู้ขอไม่ต้องเลือกประเภทรถ รถ หรือคนขับ ผู้จัดรถจะดำเนินการในขั้นจัดรถ

เมื่อกดส่งคำขอที่มีไฟล์ ระบบบันทึกร่างและอัปโหลดเอกสารก่อน หากอัปโหลดไม่สำเร็จ คำขอจะยังเป็นร่าง ให้ลองส่งอีกครั้งโดยไม่สร้างคำขอใหม่ หลังส่งแล้วผู้ขอเปิดดูเอกสารได้ แต่เพิ่มหรือลบได้เฉพาะร่างหรือรายการที่ถูกส่งกลับมาแก้ไข

> ✅ **ก่อนส่งคำขอ:** ตรวจปลายทาง วันเวลา และรายชื่อผู้ร่วมเดินทางให้ครบถ้วน โดยวันเวลากลับต้องอยู่หลังวันเวลาออกเดินทาง

## 🔎 ติดตามสถานะ

เปิดรายละเอียดจากเลขคำขอ สถานะสำคัญมีดังนี้

- 🟡 `รอจัดรถและคนขับ` — งานยานพาหนะกำลังตรวจคิว
- 🟠 `รอหัวหน้าฝ่ายบริหารตรวจสอบ` — จัดรถแล้วและรอตรวจ
- 🟣 `รอผู้อำนวยการอนุมัติ` — ผ่านการตรวจสอบแล้ว
- 🔵 `รอคนขับรับทราบ` — อนุมัติแล้วและส่งงานให้คนขับ
- 🟢 `พร้อมเดินทาง` / `กำลังเดินทาง` / `เสร็จสิ้น`
- 🔴 `ส่งกลับให้แก้ไข` / `ไม่อนุมัติ` / `ยกเลิก`

## ⭐ Feedback หลังจบทริป

เมื่อทริปเสร็จสิ้น ผู้ขอและผู้ร่วมเดินทางจริงจะเห็นปุ่ม `ให้ Feedback` ของตนเอง การประเมินของคนหนึ่งไม่ทำให้คนอื่นขึ้นว่าส่งแล้ว และระบบไม่แสดงตัวผู้ประเมินในรายงานบริหาร

> 🔐 **ความเป็นส่วนตัว:** ระบุเฉพาะข้อมูลที่จำเป็นต่อการเดินทาง ห้ามใส่ข้อมูลผู้ป่วยหรือข้อมูลสุขภาพในคำขอ

## 🛟 เมื่อพบปัญหา

- ไม่พบคำขอของตนเอง: กดรีเฟรชและตรวจบัญชีที่เข้าสู่ระบบ
- ไม่พบปุ่ม Feedback: ตรวจว่าทริปเสร็จสิ้นและชื่ออยู่ในรายชื่อผู้ร่วมเดินทางจริง
- วันที่ไม่ถูกต้อง: กำหนดวันเวลากลับให้หลังวันเวลาออกเดินทาง
