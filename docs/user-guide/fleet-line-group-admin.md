# คู่มือผู้ดูแลกลุ่มแจ้งเตือนส่วนกลาง

กลุ่ม LINE สำหรับระบบรถ แจ้งซ่อม และจองห้องประชุมจัดการที่ `จัดการระบบ` > `กลุ่มแจ้งเตือนส่วนกลาง` (`/admin/line-groups`) ใช้สิทธิ์ `LineGroup.View` เพื่อดู และ `LineGroup.Manage` เพื่อเพิ่ม แก้ไข ยืนยัน ปิดใช้งาน ตั้งเหตุการณ์ หรือทดสอบส่ง เมนู LINE Groups เดิมในจองรถไม่ใช้แล้ว

## ตั้งค่ากลุ่ม

1. กด `เพิ่มการเชื่อมต่อ` ระบุชื่อกลุ่ม Group ID, Endpoint URL แบบ HTTPS, Client ID และ Client Secret จากผู้ให้บริการ
2. ตรวจรายการสถานะ `รอยืนยัน` และกด `ยืนยัน` เมื่อข้อมูลปลายทางถูกต้อง
3. เปิด `รายละเอียด` แล้วเลือกเหตุการณ์ที่ต้องการรับ เช่น Fleet, Repair หรือ Meeting Room จากนั้นบันทึก
4. หากรับงานแจ้งซ่อม ให้เลือก `ทีมแจ้งซ่อมที่รับ` เป็น `IT` หรือ `ช่างทั่วไป` ด้วย กลุ่มที่ไม่จับคู่ทีมจะไม่รับเหตุการณ์แจ้งซ่อม
5. ใช้ `ทดสอบ` โดยไม่มีข้อมูลผู้ป่วยหรือข้อมูลอ่อนไหว แล้วตรวจ `ประวัติการส่งข้อความ` และรหัสติดตามเมื่อมีปัญหา

กลุ่มหนึ่งรับได้หลายเหตุการณ์และหลายกลุ่มรับเหตุการณ์เดียวกันได้ การปิดกลุ่มหยุดการส่งใหม่โดยยังเก็บประวัติไว้ ค่า Secret ที่บันทึกแล้วจะไม่แสดงกลับบนหน้าเว็บ

## กลุ่มแจ้งซ่อมเดิม

รายการที่ติดป้าย `กลุ่มแจ้งซ่อมเดิม · ยังไม่ได้ย้ายเข้าส่วนกลาง` ยังไม่รับข้อความผ่านตัวส่งส่วนกลาง ผู้มีสิทธิ์จัดการกด `ย้ายเข้าส่วนกลาง` แล้วตรวจ Group ID แบบปกปิด สถานะเดิม และทีมปลายทางก่อนยืนยัน ระบบคงสถานะเดิมและปิดการสมัครเหตุการณ์ทั้งหมดไว้ก่อน

หลังย้าย กด `ทดสอบ` จากหน้าส่วนกลางได้แม้กลุ่มยังปิดใช้งานอยู่ เมื่อทดสอบสำเร็จจึงเลือกเปิดเหตุการณ์ `Repair.*` ที่ต้องการ กลุ่มที่คงสถานะปิดจะยังไม่รับงานจริงจนกด `เปิดใช้งาน` แยกต่างหาก ห้ามส่งงานค้างเก่าย้อนหลังเอง

## API และการแก้ปัญหา

API ของหน้านี้อยู่ที่ `/api/admin/line-groups` และเส้นทางย่อย `/{id}/configuration`, `/{id}/confirm`, `/{id}/disable`, `/{id}/subscriptions`, `/{id}/test`, `/{id}/deliveries` การแก้ไขใช้ concurrency token และบันทึก Audit

หากหน้าโหลดไม่สำเร็จ ให้ตรวจสิทธิ์ `LineGroup.View` และ backend log ด้วย reference ID ของข้อผิดพลาด หาก API รุ่นใหม่ถูกนำขึ้น PRD แต่ฐานข้อมูลยังไม่มี `repair_team_code` และ `repair_team_assigned_at` ต้องใช้ migration `20260924150000_AddCentralLineGroupRepairTeam` ก่อน หน้าจะแจ้ง error 500 จนกว่า schema จะตรงกับ API
