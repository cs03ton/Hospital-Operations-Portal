# ระบบแจ้งซ่อม IT และช่างทั่วไป

## ผู้ใช้งาน

เปิดเมนู แจ้งซ่อม > แจ้งซ่อมใหม่ เลือกประเภท ระบุอาการ สถานที่ และผู้ติดต่อ ไม่จำเป็นต้องมีเลขครุภัณฑ์
IT รับงานคอมพิวเตอร์ เครื่องพิมพ์ เครือข่าย โปรแกรม และเครื่องมือแพทย์ ส่วนทีมช่างทั่วไปดูแลไฟฟ้า ประปา แอร์ อาคาร สุขภัณฑ์ และอุปกรณ์ทั่วไป
รูปแนบรองรับ JPG/PNG/WebP ครั้งละไม่เกิน 5 รูป รูปละไม่เกิน 10 MB หลีกเลี่ยงภาพที่มีข้อมูลผู้ป่วย

ติดตามในรายการแจ้งซ่อม ขอบเขตงานของฉัน หากทีมส่งกลับให้ตรวจเหตุผล แก้ประเภท/รายละเอียดและส่งใหม่โดยใช้เลขงานเดิม
เมื่อแก้ไขเสร็จ ให้บันทึกผลตรวจรับแล้วปิดงาน หรือเลือกยังแก้ไม่สำเร็จเพื่อให้ทีมดำเนินการต่อ
หลังปิดงานสามารถเปิดงานซ้ำพร้อมเหตุผล ระบบเริ่มรอบซ่อมใหม่และเก็บผลซ่อมเก่าไว้ครบ
งานที่ยังไม่เริ่มทำ ผู้แจ้งยกเลิกเองได้ หลังเริ่มแล้วให้ผู้ดูแลยกเลิกพร้อมเหตุผล

## ทีมช่าง

ผู้ดูแลผูก role ช่าง IT / ช่างทั่วไป กับบัญชีเดิมได้ คนเดียวมีทั้งสอง role ได้ ไม่ใช้หน่วยงานเป็นตัวให้สิทธิ์
เปิดขอบเขตงานทั้งหมดของทีม สมาชิกทุกคนเห็นงานร่วมกัน ไม่ต้องรับเคสเป็นเจ้าของ
เริ่มดำเนินการ กำหนดความเร่งด่วน เพิ่มบันทึกหรือรูปได้ เมื่อรออะไหล่ให้เปลี่ยนสถานะ และดำเนินการต่อเมื่อพร้อม
งานผิดทีมให้ส่งกลับผู้แจ้งพร้อมเหตุผล ไม่ส่งต่อโดยแก้ข้อมูลของผู้แจ้งเงียบ ๆ
ตอนแก้ไขเสร็จ ระบุผลซ่อม ผู้แก้ไขหลัก และผู้ร่วมงาน ระบบเก็บผู้กดบันทึกแยกจากผู้แก้ไข
กรณีข้อมูลเปลี่ยนพร้อมกัน ให้โหลดใหม่แล้วตรวจสถานะก่อนดำเนินการอีกครั้ง

เครื่องมือแพทย์เข้าทีม IT ในรอบแรก แต่สถานะแก้ไขเสร็จไม่ใช่ใบรับรองความปลอดภัย ให้ตรวจรับตามขั้นตอนโรงพยาบาลก่อนนำกลับใช้งาน
ระบบเก็บช่วงรออะไหล่และรอบซ่อมไว้เท่านั้น ยังไม่ตัดสินผ่าน/เกิน SLA

## ผู้ดูแล

ตั้งค่าประเภทกับทีมรับผิดชอบได้ การเปลี่ยนประเภทไม่ย้ายใบงานเก่าโดยอัตโนมัติ
ตั้งค่าหมอพร้อมแยกสองกลุ่ม IT และช่างทั่วไป โดยใช้ Endpoint URL, Client ID และ Client Secret ของแต่ละกลุ่ม
ปลายทางเริ่มปิดไว้จนกรอก credentials และเปิดส่งแจ้งเตือน ไม่ใช้ credentials ของ Fleet อัตโนมัติ
ข้อมูลกลุ่มแสดงเพียงเลขงานและลิงก์ ผู้เปิดลิงก์ต้องเข้าสู่ระบบและมีสิทธิ์ จึงจะเห็นรายละเอียด
Pending คือรอส่ง, Sent คือส่งสำเร็จ, Attention คือต้องตรวจสอบ, Sending ที่ค้างอาจส่งไปแล้ว ห้ามส่งซ้ำโดยยังไม่ตรวจฝั่งปลายทาง
