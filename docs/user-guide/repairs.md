# 🔧 คู่มือระบบแจ้งซ่อม IT และช่างทั่วไป

คู่มือนี้อธิบายการแจ้งปัญหา การติดตามงาน การดำเนินงานของทีมช่าง และการตั้งค่าระบบแจ้งซ่อมใน Hospital Operations Portal (HOP)

> 💡 **ภาพรวมเร็ว:** ผู้ใช้แจ้งปัญหา → ทีมที่รับผิดชอบเริ่มดำเนินการ → บันทึกผลซ่อม → ผู้แจ้งตรวจรับ → ปิดงาน หรือส่งกลับให้ดำเนินการต่อ

## 🧭 เมนูและขอบเขตงาน

| เมนู | ใช้ทำอะไร | ผู้ใช้งานหลัก |
|---|---|---|
| `แจ้งซ่อม` > `Dashboard แจ้งซ่อม` | ดูจำนวนงานและสถานะภาพรวมตามสิทธิ์ | ผู้ใช้และทีมช่าง |
| `แจ้งซ่อม` > `รายการแจ้งซ่อม` | ค้นหา กรอง และเปิดรายละเอียดงาน | ทุกบทบาทที่มีสิทธิ์ |
| `แจ้งซ่อม` > `แจ้งซ่อมใหม่` | สร้างใบงานใหม่ | ผู้มีสิทธิ์แจ้งซ่อม |
| `แจ้งซ่อม` > `ตั้งค่าแจ้งซ่อม` | จัดการประเภทงาน และเปิดทางไปกลุ่มแจ้งเตือนส่วนกลางตามสิทธิ์ | ผู้ดูแล |

ระบบแสดงข้อมูลตามสิทธิ์ ผู้แจ้งเห็นงานของตนเอง ส่วนสมาชิกทีมช่างเห็นคิวร่วมของทีมที่ได้รับบทบาท

## 👤 สำหรับผู้แจ้ง

### แจ้งซ่อมและปัญหาการใช้งาน

1. เปิด `แจ้งซ่อมใหม่` หน้า `แจ้งซ่อมและปัญหาการใช้งาน`
2. เลือกประเภทปัญหาให้ตรงกับงาน
3. ระบุอาการและสถานที่ ระบบดึงชื่อ–นามสกุลและเบอร์โทรผู้แจ้งจากข้อมูลส่วนตัวมาแสดงเป็นช่องที่แก้ไขไม่ได้ หากยังไม่มีเบอร์ ให้เพิ่มใน `ข้อมูลส่วนตัวของฉัน` ก่อนส่ง
4. ใส่เลขครุภัณฑ์หากมี รายการที่ไม่มีเลขครุภัณฑ์ยังแจ้งได้
5. แนบรูป JPG, PNG หรือ WebP ได้สูงสุด 5 รูป รูปละไม่เกิน 10 MB
6. ตรวจข้อมูลแล้วส่งรายการ

| ทีม | ตัวอย่างงาน |
|---|---|
| IT | คอมพิวเตอร์ เครื่องพิมพ์ เครือข่าย โปรแกรม และเครื่องมือแพทย์ในขอบเขตรอบแรก |
| ช่างทั่วไป | ไฟฟ้า ประปา เครื่องปรับอากาศ อาคาร สุขภัณฑ์ และอุปกรณ์ทั่วไป |

> 🔐 หลีกเลี่ยงภาพหน้าจอ เอกสาร หรือภาพสถานที่ที่มีชื่อผู้ป่วย HN ข้อมูลสุขภาพ หรือข้อมูลส่วนบุคคลที่ไม่เกี่ยวกับงานซ่อม

### ติดตามและตอบกลับงาน

1. เปิด `รายการแจ้งซ่อม` และเลือกขอบเขต `งานของฉัน`
2. ค้นหาจากเลขงานหรือรายละเอียด
3. เปิดรายการเพื่อตรวจสถานะ บันทึก และรูปประกอบ
4. หากทีมส่งกลับ ให้ตรวจเหตุผล แก้ประเภทหรือรายละเอียด แล้วส่งใหม่ ระบบใช้เลขงานเดิม
5. เมื่อทีมบันทึกว่าแก้ไขเสร็จ ให้ตรวจรับผล
6. เลือกปิดงานเมื่อใช้งานได้ หรือเลือกว่ายังแก้ไม่สำเร็จเพื่อส่งกลับให้ทีมดำเนินการต่อ

งานที่ยังไม่เริ่มดำเนินการ ผู้แจ้งยกเลิกเองได้ หลังทีมเริ่มงานแล้วให้ติดต่อผู้ดูแลเพื่อยกเลิกพร้อมเหตุผล

### เปิดงานซ้ำ

หลังปิดงาน หากปัญหาเดิมกลับมา สามารถเปิดงานซ้ำพร้อมระบุเหตุผล ระบบจะเริ่มรอบซ่อมใหม่โดยเก็บผลซ่อมและประวัติรอบก่อนหน้าไว้

## 🧑‍🔧 สำหรับทีมช่าง

ผู้ดูแลกำหนดบทบาท `ช่าง IT` หรือ `ช่างทั่วไป` ให้บัญชีผู้ใช้เดิมได้ คนเดียวสามารถมีทั้งสองบทบาท ทีมใช้คิวร่วมและไม่จำเป็นต้องรับเคสเป็นเจ้าของก่อนเห็นงาน

### ดำเนินงาน

1. เปิด `รายการแจ้งซ่อม` และเลือกขอบเขตงานของทีม
2. ตรวจประเภท อาการ สถานที่ ผู้ติดต่อ รูปแนบ และประวัติ
3. กดเริ่มดำเนินการและกำหนดความเร่งด่วนตามข้อมูลจริง
4. เพิ่มบันทึกหรือรูปความคืบหน้าเมื่อมีข้อมูลสำคัญ
5. หากรออะไหล่ ให้เปลี่ยนสถานะและกลับมาดำเนินการต่อเมื่อพร้อม
6. เมื่อแก้ไขเสร็จ ระบุผลซ่อม ผู้แก้ไขหลัก และผู้ร่วมงาน
7. ส่งให้ผู้แจ้งตรวจรับ

หากงานผิดทีม ให้ส่งกลับผู้แจ้งพร้อมเหตุผล เพื่อให้ผู้แจ้งแก้ประเภทหรือรายละเอียด ห้ามเปลี่ยนข้อมูลแทนผู้แจ้งโดยไม่มีคำอธิบาย

กรณีข้อมูลถูกเปลี่ยนพร้อมกัน ให้โหลดรายการล่าสุด ตรวจสถานะและประวัติ แล้วดำเนินการใหม่เพื่อป้องกันการทับข้อมูล

> ⚠️ สถานะ `แก้ไขเสร็จ` ของเครื่องมือแพทย์ไม่ใช่ใบรับรองความปลอดภัย ต้องผ่านขั้นตอนตรวจรับตามนโยบายโรงพยาบาลก่อนนำกลับใช้งาน

## ⚙️ สำหรับผู้ดูแล

### ประเภทงานและทีมรับผิดชอบ

- กำหนดชื่อประเภท สถานะ และทีมรับผิดชอบให้ชัดเจน
- การเปลี่ยนทีมของประเภทไม่มีผลย้ายใบงานเก่าโดยอัตโนมัติ
- ใช้สถานะปิดใช้งานกับประเภทที่เลิกใช้เพื่อรักษาประวัติ
- กำหนดบทบาททีมช่างจากหน้าจัดการผู้ใช้และบทบาท ไม่ใช้ชื่อหน่วยงานเป็นตัวให้สิทธิ์

### การแจ้งเตือนผ่านกลุ่มส่วนกลาง

เปิด `จัดการระบบ` > `กลุ่มแจ้งเตือนส่วนกลาง` ด้วยสิทธิ์ `LineGroup.View` หรือ `LineGroup.Manage` การตั้งค่าปลายทางและ credentials อยู่ที่หน้านี้เพียงแห่งเดียว ไม่มีแท็บตั้งค่ากลุ่มหรือ `ผลส่งเดิม` ในหน้าตั้งค่าแจ้งซ่อมแล้ว

ผู้ดูแลเลือก `ทีมแจ้งซ่อมที่รับ` เป็น `IT` หรือ `ช่างทั่วไป` ให้แต่ละกลุ่ม แล้วเปิดเหตุการณ์ `Repair.*` ที่ต้องการ กลุ่มต้องเปิดใช้งานและยืนยันแล้วจึงรับงานของทีมที่ตรงกัน กลุ่มที่ยังไม่จับคู่ทีมจะไม่รับข้อความแจ้งซ่อม ผลส่งใหม่ตรวจจากรายละเอียดกลุ่มและ Delivery Log ของส่วนกลาง

กลุ่มแจ้งซ่อมเดิมที่มี `module` ขึ้นต้นด้วย `REPAIR_` อาจแสดงป้าย `รอย้ายเข้าส่วนกลาง` ผู้ดูแลต้องยืนยันการย้ายรายกลุ่ม ทดสอบส่ง แล้วเลือกเหตุการณ์ที่ต้องการ กลุ่มที่เดิมปิดใช้งานจะยังปิดอยู่จนกดเปิดเอง อย่าส่งรายการค้างย้อนหลังโดยไม่ตรวจข้อมูลก่อน

ข้อความแจ้งเตือนแสดงเฉพาะเลขงานและลิงก์ ผู้เปิดลิงก์ต้อง Login และมีสิทธิ์จึงจะเห็นรายละเอียด ห้ามบันทึก credential จริงลงคู่มือหรือ source code

## 📌 สถานะงานที่ควรรู้

- รอดำเนินการ: อยู่ในคิวของทีม
- กำลังดำเนินการ: ทีมเริ่มตรวจหรือซ่อมแล้ว
- รออะไหล่: พักเวลาไว้จนมีอะไหล่พร้อม
- ส่งกลับผู้แจ้ง: ต้องแก้ประเภทหรือข้อมูลก่อนส่งใหม่
- รอตรวจรับ: ทีมบันทึกผลเสร็จและรอผู้แจ้งยืนยัน
- ปิดงาน: ผู้แจ้งตรวจรับแล้ว
- ยกเลิก: งานไม่ต้องดำเนินการต่อ
- เปิดงานซ้ำ: เริ่มรอบใหม่จากงานเดิมพร้อมเก็บประวัติ

ระบบเก็บช่วงรออะไหล่และรอบซ่อมไว้เพื่อการตรวจสอบ แต่ยังไม่ตัดสินผ่านหรือเกิน SLA โดยอัตโนมัติ

## 🧯 แก้ปัญหาเบื้องต้น

- ไม่เห็นงานของทีม: ตรวจบทบาทช่าง สถานะบัญชี และขอบเขตที่เลือก
- ส่งรูปไม่ได้: ตรวจชนิดไฟล์ จำนวนไฟล์ ขนาด และลองอัปโหลดใหม่
- ปุ่มดำเนินการไม่แสดง: โหลดข้อมูลล่าสุดและตรวจว่าสถานะยังอนุญาตให้ทำรายการนั้น
- งานอยู่ผิดทีม: ส่งกลับพร้อมเหตุผลให้ผู้แจ้งแก้ประเภท
- แจ้งเตือนไม่ออก: ตรวจว่ากลุ่มส่วนกลาง active ยืนยันแล้ว จับคู่ทีมถูกต้อง และเปิดเหตุการณ์ที่เกี่ยวข้อง จากนั้นตรวจ Delivery Log ก่อนสั่งทดสอบหรือส่งซ้ำ
- ต้องแจ้ง IT: ระบุเลขงาน เวลาโดยประมาณ ขั้นตอนที่ทำ และข้อความผิดพลาด โดยไม่ส่งข้อมูลผู้ป่วย
