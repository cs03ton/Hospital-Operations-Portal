# 📋 คู่มือหัวหน้าฝ่ายบริหารตรวจคำขอรถ

คู่มือนี้สำหรับ role `FleetAdminReviewer` หรือผู้ได้รับสิทธิ์ตรวจคำขอหลังงานยานพาหนะจัดรถและคนขับแล้ว

> 💡 **ภาพรวมเร็ว:** ตรวจคำขอที่จัดรถแล้ว → ตรวจความเหมาะสม → อนุมัติส่งต่อหรือส่งกลับพร้อมเหตุผล

## 🔍 ตรวจรายการ

1. เปิด `จองรถ > งานรอตรวจสอบและอนุมัติคำขอใช้รถ`
2. ระบบแสดงส่วน `หัวหน้าฝ่ายบริหารตรวจสอบ` เฉพาะรายการในขั้นตอนของคุณ
3. เปิดรายละเอียดเพื่อตรวจผู้ขอ ภารกิจ เวลา ปลายทาง ผู้ร่วมเดินทาง รถ คนขับ และ Timeline
4. เลือกการดำเนินการ

## ✅ การตัดสินใจ

- `อนุมัติและส่งต่อ` — ส่งให้ผู้อำนวยการอนุมัติขั้นสุดท้าย
- `ส่งกลับแก้ไข` — ส่งกลับตามต้นเหตุและระบุเหตุผล
- `ไม่อนุมัติ` — จบคำขอพร้อมเหตุผล

ทุก action ตรวจ permission, สถานะล่าสุด และ concurrency ฝั่ง server หากข้อมูลเปลี่ยนระหว่างเปิดหน้า ระบบจะแจ้ง Conflict ให้รีเฟรชก่อนทำใหม่

> ⚠️ **ข้อควรระวัง:** ตรวจเฉพาะคำขอที่อยู่ในขั้นตอนของหัวหน้าฝ่ายบริหาร และไม่แก้ไข Assignment โดยตรง

## 🎯 ขอบเขตบทบาท

หัวหน้าฝ่ายบริหารสามารถสร้างคำขอใช้รถของตนเองได้ แต่รายการตรวจจะแสดงเฉพาะงานที่อยู่ในขั้นตอนตรวจสอบ ไม่ควรใช้บัญชีร่วมกัน และไม่ควรดำเนินการแทนผู้อื่นโดยไม่มี Delegation ที่ยังมีผล
