# เอกสาร ฉ.11

เมนูงานสารบรรณ → สร้างเอกสาร ฉ.11 (`/correspondence/cho11`) ใช้สิทธิ์ `Correspondence.Use` ทั้งเมนู หน้าเว็บ และ API

- เลือกเดือน/ปีเอกสารเริ่มต้น–สิ้นสุดได้ไม่เกิน 12 เดือน สร้างหนึ่งหน้าต่อเดือน รวมเดือนต้นและปลาย
- กรอกวัน/เดือน/ปีเริ่มงานเอง อายุงานเริ่มจากวันที่เลือกถึงสิ้นเดือนในแต่ละหน้า นับรวมวันสุดท้าย แสดงปี เดือน และวันตามปฏิทิน ไม่อ่านหรือแก้วันที่เริ่มงานใน Profile
- ชื่อพร้อมคำนำหน้าของผู้ขอ/ผู้ตรวจสอบตรวจจากบัญชีจริงเมื่อสร้างไฟล์ ผู้ขอเลือกจากบุคลากรที่เปิดใช้งานทุกหน่วยงาน ค่าเริ่มต้นเจ้าของบัญชี เมื่อเลือกจะเติมตำแหน่งจากบัญชีและแก้เฉพาะเอกสารนี้ได้ โดยไม่แก้ Profile ผู้ตรวจสอบเลือกได้จากผู้อนุมัติที่เปิดใช้งาน ค่าเริ่มต้นหัวหน้าหน่วยงานตนเองเฉพาะเมื่อมีคนเดียว
- ข้อมูลโรงพยาบาล/จังหวัดแก้ได้ ค่าเริ่มต้นและระดับพื้นที่ตั้งใน `Correspondence:Cho11` ใน appsettings
- ประวัติในข้อ 2 และยอดรวมใช้ช่วงหน่วยบริการปัจจุบันเท่านั้น ช่องประวัติอื่นเว้นเส้นประ ไม่สร้างประวัติสมมติ

`GET /api/correspondence/cho11/options` ส่งข้อมูลผู้ทำเอกสาร ผู้ตรวจสอบ หัวหน้า รายชื่อบุคลากร `people` (เฉพาะ ID ชื่อ คำนำหน้า ตำแหน่ง และรหัสหน่วยงาน) และค่าเริ่มต้น โดยไม่มี credentials

`POST /api/correspondence/cho11/render` รับ `startMonth`, `endMonth` เป็น `yyyy-MM` และ `employmentDate` เป็น `yyyy-MM-dd` ปี ค.ศ. (client เดิมที่ส่งเฉพาะ `employmentMonth` ยังใช้วันที่ 1 ของเดือนนั้นได้), `hospital`, `province`, `reviewerUserId`, `authorUserId` และ `authorPosition` (สองค่าหลังไม่ส่งใช้เจ้าของบัญชีและตำแหน่งจากบัญชีเดิม) และส่ง `MemoFiles` ตามสัญญาเดิม (DOCX/PDF base64, fileName, templateVersion) เดือน/ปีบนฟอร์มเป็น พ.ศ. และเอกสารใช้เลขไทยสำหรับวันเวลาและอายุงาน

เนื้อหาจัดเต็มบรรทัด และย่อหน้าข้อความรับรองสองย่อหน้าสุดท้ายเยื้องบรรทัดแรก 1.25 ซม.

DOCX/PDF รวมทุกเดือนในไฟล์เดียวต่อชนิด หน้า A4 แนวตั้ง TH SarabunPSK ไม่มีลายเซ็นหรือขั้นตอนอนุมัติ เก็บข้อมูลและไฟล์เฉพาะหน่วยความจำ ไม่บันทึกลงฐานข้อมูล ดิสก์ cache หรือ log เมื่อแก้ฟอร์ม Preview เดิมหมดอายุ เมื่อออก/ล้าง/แทนที่ Preview จะคืน object URLs

ไม่ต้องมี migration การติดตั้งใช้ build/publish ตาม `AGENTS.md` โดยไม่ deploy หรือเปลี่ยนข้อมูล PRD จากงานพัฒนา
