# เพิ่มคำนำหน้าชื่อผู้ใช้

เพิ่ม `public.users.name_prefix` เป็น `varchar(100) NULL` ไม่มีค่าเริ่มต้น แยกจาก `fullname` บัญชีเดิมจึงมีค่า `NULL` โดยไม่แก้ชื่อหรือเดาคำนำหน้าจากเพศ

Backend รองรับผ่าน `User.NamePrefix` และ EF migration `20261106030602_AddUserNamePrefix` หน้าข้อมูลส่วนตัวอ่านและแก้คำนำหน้าแยกจากชื่อ–นามสกุลผ่าน `GET/PUT /api/me/profile` ฟิลด์ `namePrefix` ความยาวไม่เกิน 100 ตัวอักษร ตัดช่องว่างหัวท้ายและบันทึก Audit ตามเดิม ยังไม่เปลี่ยนการประกอบชื่อในเอกสารหรือหน้าจัดการผู้ใช้

คำขอแก้ Profile ที่ไม่ส่ง `namePrefix` หรือส่ง `null` จะคงค่าเดิมเพื่อรองรับ client เก่า ส่วนข้อความว่างใช้ล้างคำนำหน้าเป็น `NULL` หน้าจอใหม่ส่งข้อความว่างเมื่อผู้ใช้ล้างช่องนี้

## รันผ่าน DBeaver

1. เลือก connection และฐานข้อมูล HOP ที่ต้องการติดตั้ง ตรวจชื่อฐานข้อมูลให้ถูกต้อง
2. เปิด `docs/sql/user-name-prefix.sql` ใน SQL Editor แล้วใช้ **Execute SQL Script (Alt+X)** ทั้งไฟล์ ไม่รันเฉพาะคำสั่ง ALTER แยกเดี่ยว
3. ตรวจผลลัพธ์ท้ายไฟล์: คอลัมน์เป็น `character varying` ความยาว `100`, `is_nullable = YES`, ไม่มี default และมี migration ID ข้างต้นหนึ่งรายการ

สคริปต์ทำงานใน transaction เดียวและบันทึก EF migration history พร้อมกัน รันซ้ำได้โดยไม่เปลี่ยนข้อมูล หากมีคอลัมน์อยู่แล้วแต่โครงสร้างไม่ตรงจะหยุด ไม่แก้ชนิดคอลัมน์อัตโนมัติ หาก DBeaver แจ้ง transaction aborted ให้รัน `ROLLBACK;` แล้วแก้สาเหตุหรือเลือกฐานข้อมูลให้ถูกต้องก่อนรันใหม่

ต้องติดตั้ง schema นี้ก่อนใช้ Backend เวอร์ชันใหม่ เพราะ EF เริ่มอ่านคอลัมน์ใหม่นี้แม้หน้าจอยังไม่ใช้ ไม่ต้องรัน EF migration เดิมทั้งหมดอีกครั้งเมื่อใช้ SQL นี้แล้ว การติดตั้งนี้ไม่ควรใช้แทน migration อื่นที่ยังค้างอยู่

ตัวอย่างอ่านข้อมูลโดยไม่แก้ไข:

```sql
SELECT id, employee_code, name_prefix, fullname, username
FROM public.users
ORDER BY fullname
LIMIT 50;
```

คำสั่งข้างต้นแสดง `name_prefix` ระหว่าง `employee_code` และ `fullname` ตามลำดับที่ต้องการในผลลัพธ์ DBeaver ส่วนลำดับคอลัมน์จริงในตาราง PostgreSQL จะเพิ่มไว้ท้ายตาราง เพราะ `ALTER TABLE ADD COLUMN` ไม่รองรับ `BEFORE` / `AFTER` งานนี้ไม่สร้างตารางใหม่เพื่อจัดลำดับคอลัมน์

ไม่มีการเชื่อมต่อหรือเปลี่ยน PRD อัตโนมัติ และไม่มีการ deploy ในงานนี้
