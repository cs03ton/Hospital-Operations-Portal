# Fleet Requester Guide (Planned)

พนักงาน active จะสร้าง draft ระบุภารกิจ ปลายทาง ช่วงเวลา จำนวนผู้โดยสาร ผู้ประสานงาน และความต้องการพิเศษ โดยไม่สามารถเลือกรถหรือคนขับเองได้

คำสั่งคัดลอกจะสร้าง draft ใหม่และให้ยืนยันรายชื่อผู้ร่วมเดินทางใหม่ ก่อน submit ระบบตรวจข้อมูลครบ ช่วงเวลาถูกต้อง และป้องกันการกดซ้ำ
# Dashboard รถ

เปิด `จองรถ > Dashboard รถ` เพื่อดูสถานะคำขอของตนเอง งานที่ต้องแก้ไข และการเดินทางถัดไป ปุ่มใน Dashboard จะพาไปยังรายละเอียดที่ยังตรวจสิทธิ์ตามปกติ หากไม่มีรายการ ระบบจะแสดง empty state แทนข้อมูลของบุคคลอื่น
