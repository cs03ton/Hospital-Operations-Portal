# Fleet Driver Guide (Planned)

คนขับเห็นเฉพาะงานที่จัดให้ตนเองบนหน้าจอ mobile-first: รับทราบ เริ่มงาน และปิดงาน การปิดงานต้องบันทึกเวลาจริง เลขไมล์ และเหตุการณ์ (ถ้ามี); เลขไมล์ปลายห้ามน้อยกว่าเลขไมล์ต้น
# Dashboard รถสำหรับคนขับ

Dashboard แสดงเฉพาะ Assignment ของผู้ใช้ที่เข้าสู่ระบบ ได้แก่ งานวันนี้ งานถัดไป งานที่ต้องตอบรับ และสรุประยะทาง กด `เปิดงานขับรถ` เพื่อรับทราบ เริ่ม หรือปิดงานตามสถานะ
