# Fleet Dispatcher Guide (Planned)

Dispatcher ตรวจคิว ดูรถ/คนขับพร้อมเหตุผลและข้อมูลหมุนเวียน แล้วเป็นผู้ตัดสินใจ assign เอง ระบบไม่ auto-assign การเปลี่ยน assignment หลังอนุมัติต้องระบุเหตุผล ปิดรายการเดิม สร้างรายการใหม่ และแจ้งผู้ได้รับผลกระทบ
# Dashboard รถสำหรับ Dispatcher

ใช้ส่วน `งานจัดรถ` เพื่อตรวจคิวรอจัดรถ รถ/คนขับที่พร้อม งานส่งกลับ และงานเกินกำหนด Badge ใน Sidebar ใช้ count เดียวกับ Dashboard และจะปรับหลัง action สำเร็จ
